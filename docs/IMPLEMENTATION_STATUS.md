## Deliberate departures from unsafe literal snippets

The plan suggests adding a global `.js` class before hiding reveal content. That still fails if the marker runs but the enhancement bundle does not. This implementation never makes core content invisible; optional entrance movement is added only to already-visible content.

Before/after examples are genuine new concept artifacts, never relabeled as real client screenshots. The studio is described as in development. No made-up availability, testimonials, clients, interviews, revenue uplift or staff identity is introduced.

Contact delivery has a functional local-brief mode until verified external configuration exists. No fabricated address, secret or domain is used. An email-service acceptance response is distinguished from actual inbox delivery.

## Not a completed external launch

No AWS deployment, SES identity verification, domain purchase, provider account, secret, public email address or personal biography is created by committing this code. No real-user test or 9/10 grade is asserted. Those are explicit completion dependencies, not hidden omissions.
