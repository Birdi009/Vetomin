# Quiet Compass

A free, open-source, static-first business/portfolio website template built from the Quiet Compass design brief: calm wayfinding, editorial minimalism, semi-minimal sign motifs, elemental color roles, and restrained interaction.

## Included
- Home, About, Work, Journal, Contact
- Responsive layout
- Reduced-motion support
- Semantic, keyboard-friendly baseline
- CSS/IntersectionObserver interaction layer
- GitHub Pages workflow
- AWS S3 + CloudFront deployment notes
- No framework or paid dependency required

## GitHub Pages
Repository Settings → Pages → Source: GitHub Actions. The included workflow publishes the site automatically.

## Customize
Start with `assets/style.css`. Design tokens: Ink #202622, Porcelain #F6F1E8, Water #17384C, Wood #355A42, Earth #D8C7AA, Fire #963B2F.

## Contact form
The included form is a front-end demo. Connect it to a form provider or AWS API Gateway/Lambda for submissions.
